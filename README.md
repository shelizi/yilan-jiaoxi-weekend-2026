# 宜蘭山海慢旅｜2026/11/28（六）–11/29（日）

公開網站：https://shelizi.github.io/yilan-jiaoxi-weekend-2026/

## 行程重排：礁溪與冬山分兩天

### 週六 11/28｜泰山 → 北投投票 → 龍潭湖 → 礁溪
- 07:20 泰山仁愛路出發。
- 08:00 北投國小投票（臺北市北投區中央北路一段73號）。請以投票通知單確認實際投票所與教室。
- 08:30 預計投票完成後從北投國小出發往礁溪；若現場排隊較久，依實際完成時間出發，不必為趕行程縮短投票時間。
- 11:00 龍潭湖短版湖畔散步約50–60分鐘。若要完整探索與環湖，建議增加到90–120分鐘；官方建議深度遊覽約2–3小時。
- 12:15 礁溪午餐：葷食拾松辦桌小吃；素食 Mercy 暮曦蔬食創意料理（約60–75分鐘）。
- 15:00 後長榮鳳凰酒店入住。
- 16:15 飯店溫泉 SPA。
- 18:15 晚餐：葷食御園料理；素食長春素食名人館。
- 19:45 湯圍溝溫泉公園泡腳與夜間散步。飯店至公園約0.8公里，建議步行，不需重新移車。

### 週日 11/29｜飯店早餐 → 冬山午餐 → 梅花湖 → 三清宮 → 泰山
- 08:30 長榮鳳凰酒店桂冠自助早餐（固定）。
- 10:30 整理行李，11:00前退房。
- 11:30 冬山午餐：葷食春不老驛站牛肉麵；素食白蓮寺不二齋－喜悅素鍋。
- 12:45 梅花湖散步／環湖，建議50–60分鐘；完整環湖約2.2公里。
- 14:00 道教總廟三清宮，參拜與俯瞰梅花湖，約45–60分鐘；梅花湖至三清宮開車約7分鐘。若步行上山約15分鐘且有坡度，這次建議自駕上去。
- 15:00左右離開冬山，返回泰山仁愛路。OSRM無塞車道路模型估算約82分鐘，實際依國5／雪隧當日路況調整。

## 道路順序與車程核對

以 OpenStreetMap／OSRM 公開道路網比較景點順序，餐廳部分使用附近道路座標近似，僅供比較方向與繞行，不是店門精確導航，也不含即時車流。

- 飯店 → 龍潭湖：約8.4公里／14分鐘。
- 龍潭湖 → Mercy 暮曦蔬食創意料理 → 飯店：導航已更新為玉龍路一段55號；不沿用舊餐廳地址的 OSRM 車程估算，出發時以 Google Maps 即時路線為準。
- 飯店 → 春不老驛站附近道路：約23.4公里／32分鐘。
- 飯店 → 白蓮寺不二齋附近道路：約20.7公里／27分鐘。
- 春不老 → 梅花湖：約3.8公里／7分鐘；白蓮寺不二齋 → 梅花湖：約4.9公里／8分鐘。
- 梅花湖 → 三清宮：約2.9公里／7分鐘。
- 三清宮 → 泰山仁愛路：約82.1公里／82分鐘（OSRM無塞車模型）。

因此本次週六採「北投（預計08:30投票後出發）→ 龍潭湖 → Mercy／拾松午餐 → 飯店」；週日採「飯店 → 冬山午餐 → 梅花湖 → 三清宮 → 泰山」。週日不再安排外澳、北關，避免往頭城北上後再折回冬山。

## 投票日交通與雨天備案

- 高公局預估11/28國5南向09:00–16:00易壅塞；投票後抵達龍潭湖的時間不保證。
- 若Google Maps預估趕不上午餐預約，使用網站「塞車直達午餐」路線，略過龍潭湖。
- 週六大雨：略過龍潭湖，改金車生技室內海洋生態館；晚間湯圍溝視雨勢取消。
- 週日大雨／雷雨：冬山午餐後直接北返，取消梅花湖環湖及三清宮山坡停留；若只是毛毛雨，依現場安全狀況決定是否短停。
- 出發前以Google Maps與高公局1968查看即時路況；不要將OSRM無塞車時間當作到達保證。
