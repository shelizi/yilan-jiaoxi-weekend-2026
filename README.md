# 宜蘭山海慢旅｜2026/11/21–11/22

靜態單頁網站，直接雙擊 `index.html` 即可開啟，不需要 Node.js、打包工具或伺服器。

## 行程
- 週六：新北市泰山區仁愛路出發 → 五峰旗瀑布 → 礁溪午餐 → 林美石磐步道開放段 → 長榮鳳凰酒店入住與 SPA → 礁溪晚餐 → 湯圍溝公園
- 週日：長榮鳳凰酒店桂冠自助早餐（固定）→ 11:00 前退房 → 外澳海灘 → 頭城午餐 → 北關海潮公園 → 返回泰山仁愛路
- 午、晚餐支援葷／素切換，導航網址會依飲食選擇同步變更
- 自駕起點／返程終點：新北市泰山區仁愛路（未提供門牌，Google Maps 可能定位到仁愛路中段；開啟導航後請確認精確上車位置）

## 功能
1. 桌面與手機版 RWD 響應式視覺
2. 週六、週日或完整兩日行程篩選
3. 葷食／素食雙版本餐廳與菜色建議
4. 各景點「從目前位置導航」與「前一站 → 本站路線」，週六分成山線、晚間兩段，週日含返程的 Google Maps 導航（每段最多 3 個中途點，符合手機瀏覽器限制）
5. 飯店早餐固定提示、步道／施工與雨天備案
6. 複製純文字行程與列印（另存 PDF）

## Google Maps 導航說明
- 點「山線導航」：泰山仁愛路 → 五峰旗 → 午餐（葷／素）→ 林美石磐 → 長榮鳳凰酒店。
- 點「晚間導航」：長榮鳳凰酒店 → 晚餐（葷／素）→ 湯圍溝 → 長榮鳳凰酒店。
- 點「海線＋返家導航」：飯店 → 外澳 → 午餐（葷／素）→ 北關海潮公園 → 泰山仁愛路。
- 每一站「從目前位置導航」不指定起點，以手機實際 GPS 位置為起點；「前一站 → 此站」則使用預定前一站起點。
- 連結使用 Google Maps 官方 Maps URLs（api=1, travelmode=driving, dir_action=navigate）；手機可跳至 Google Maps App，電腦通常顯示路線預覽。是否直接進入逐步導航取決於設備定位與 App 支援。

## 查核與提醒（2026/11/21）
- 長榮鳳凰酒店官網：入住 15:00 後、退房 11:00 前。桂冠自助餐廳有 08:30–10:00 的早午餐時段；實際訂房方案及排定餐期請向飯店確認。
- 林業保育署公告：林美石磐步道只開放 0–0.9K，後段封閉，務必折返。
- 北關海潮公園 2026/10/01–2027/12/31 賣店施工；步道、停車場與公廁正常開放。
- 五峰旗上層賞瀑區域有近期落石管制資訊；以現場為準，避免走封閉路段。
- 餐廳營業時間依公開資料整理，實際請向店家再次確認，葷素、蛋奶與五辛成分另確認。
- 行程時間是建議估算，不是即時車程；國道五號假日請以導航為準。
