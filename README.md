## 天氣與降雨機率

- 2026/11/21 查詢 **AccuWeather 礁溪 10 日預報**：11/28 降雨機率約 **55%**、15–25°C（可能短暫雨）；11/29 約 **0%**、17–24°C（局部晴朗）。這是較早的民間預測，並非現場實況或中央氣象署正式百分比。
- 頁面載入時及按下「更新天氣」時，從 **Open-Meteo** 免金鑰預報 API 取得礁溪附近 2026/11/28、11/29 每日最高降雨機率、最高最低氣溫與天氣代碼，會顯示更新時間和來源。
- 若網路或 API 失敗，顯示 AccuWeather 11/21 的備援數字和告知；不虛構新預報。
- 不同服務預報可能不一致，距離出發還有數日，務必於出發前再看 **中央氣象署**；大雨、雷雨與海邊強浪時，直接採雨備。

- 五峰旗改為 **金車生技水產養殖研發中心**（宜蘭縣礁溪鄉淇武蘭路162-13號），園區官方 08:00–17:00，有全室內海洋生態展示。

**週日：**

- 外澳海灘改為 **蘭陽博物館**（宜蘭縣頭城鎮青雲路三段750號），週日 09:00–17:00；建議參觀約1.5–2小時。
- 取消北關海潮公園，午餐後提早返泰山。
- 葷素餐廳仍可獨立切換。

## 導航路線（Google Maps）

- **投票導航：** 泰山仁愛路 → 北投國小
- **週六山線／雨備導航：** **北投國小** → 五峰旗或金車室內海洋館 → 午餐（葷／素）→ 林美石磐或飯店 → 礁溪長榮鳳凰酒店
- **週六晚間：** 長榮飯店 → 晚餐（葷／素）→ 湯圍溝（晴天版）→ 長榮飯店
- **週日：** 飯店 → 外澳或蘭陽博物館 → 午餐（葷／素）→ 北關（晴天版）→ 泰山仁愛路
- 每個行程項目有「從目前位置導航」、「前一站 → 此站路線」與「查看地點」；手機版 Google Maps 每段最多三個中途點，開啟後按 App 提示開始導航。
- 路線都可以按需修改起訖點；投票地點並非已確認個人分配的投票所。
