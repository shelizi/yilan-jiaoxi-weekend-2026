# 宜蘭山海慢旅｜2026/11/28（六）–11/29（日）

公開網站：https://shelizi.github.io/yilan-jiaoxi-weekend-2026/

## 行程重排：礁溪與冬山分兩天

### 週六 11/28｜泰山 → 北投投票 → 龍潭湖 → 礁溪
- 08:30 泰山仁愛路出發。
- 約09:00 抵達北投國小投票（臺北市北投區中央北路一段73號），預留45–60分鐘；請以投票通知單確認實際投票所與教室。
- 預計09:45–10:00 投票完成後從北投國小出發往礁溪；若現場排隊較久，依實際完成時間出發，不必為趕行程縮短投票時間。
- 12:00 龍潭湖短版湖畔散步約40–50分鐘，抵達時間依國5車流調整；若延誤就略過湖區直達午餐。
- 12:45 礁溪午餐：葷食拾松辦桌小吃；素食 Mercy 暮曦蔬食創意料理（約60–75分鐘）。
- 15:00 後長榮鳳凰酒店入住。
- 16:15 飯店溫泉 SPA。
- 18:15 晚餐：葷食御園料理；素食長春素食名人館。
- 19:45 湯圍溝溫泉公園泡腳與夜間散步。飯店至公園約0.8公里，建議步行，不需重新移車。

### 週日 11/29｜飯店早午餐 → 退房寄放行李 → 梅花湖 → 三清宮 → 台北晚餐 → 泰山
- 10:00–11:30 長榮鳳凰酒店桂冠自助早午餐，不另安排午餐。
- 10:45左右辦理退房，11:00前完成；行李寄放大廳，回餐廳用餐至11:30。
- 11:30 領取行李、取車直接往梅花湖。
- 12:15 梅花湖散步／環湖約70分鐘，完整環湖約2.2公里。
- 13:40 道教總廟三清宮參拜與觀景，約50分鐘。
- 14:30 北返台北，預留假日車流緩衝。
- 17:30 台北晚餐，餐廳待定，未訂位。
- 18:45 晚餐後返回泰山仁愛路，時間依路況調整。

## 道路順序與車程核對

以 OpenStreetMap／OSRM 公開道路網比較景點順序，餐廳部分使用附近道路座標近似，僅供比較方向與繞行，不是店門精確導航，也不含即時車流。

- 飯店 → 龍潭湖：約8.4公里／14分鐘。
- 龍潭湖 → Mercy 暮曦蔬食創意料理 → 飯店：導航已更新為玉龍路一段55號；不沿用舊餐廳地址的 OSRM 車程估算，出發時以 Google Maps 即時路線為準。
- 梅花湖 → 三清宮：約2.9公里／7分鐘。
- 三清宮 → 泰山仁愛路：約82.1公里／82分鐘（OSRM無塞車模型）。

因此本次週六採「泰山08:30出發 → 北投投票 → 預計09:45–10:00離開北投 → 龍潭湖（交通順暢才停留）→ 12:45午餐 → 飯店」；週日採「10:00–11:30飯店早午餐 → 11:00前退房及寄放行李 → 11:30取行李出發 → 12:15梅花湖 → 13:40三清宮 → 14:30北返台北 → 17:30晚餐（餐廳待定） → 18:45回泰山」。週日不再安排外澳、北關，避免往頭城北上後再折回冬山。

## 投票日交通與雨天備案

- 高公局預估11/28國5南向09:00–16:00易壅塞；08:30從泰山出發後，投票及車流都可能影響抵達龍潭湖時間。
- 若Google Maps預估趕不上午餐，使用網站「塞車直達午餐」路線，略過龍潭湖；葷食拾松午餐時段至14:00，延誤時先電話確認。
- 週六大雨：略過龍潭湖，改金車生技室內海洋生態館；晚間湯圍溝視雨勢取消。
- 週日大雨／雷雨：早午餐、退房及寄放行李照常，11:30取行李後直接北返台北，取消冬山戶外景點，晚餐及返家照常。
- 出發前以Google Maps與高公局1968查看即時路況；不要將OSRM無塞車時間當作到達保證。
