## 四人自駕實戰版（時間為規劃估算）
### 週六 11/28｜泰山 → 北投投票 → 午餐 → 龍潭湖／林美 → 礁溪
- 08:30 泰山仁愛路出發；09:00左右抵達北投國小周邊。
- 09:00–10:15/10:30 停車、步行、排隊投票；依通知單確認投票所。
- 10:15–10:30離開北投；國5南向預估09:00–16:00易塞，優先直達午餐。
- 約13:00 午餐：葷食礁溪漁田村；素食 Mercy 暮曦蔬食創意料理。預估13:15後抵達先電詢收客；14:15–14:30預留兩店接送會合；時間不足就略過景點。
- 14:30–15:10 龍潭湖短遊；林美為替代選項（非雙步道），雨天改金車室內海洋館。
- 15:40飯店入住（林美版16:00）；16:20–17:30泡湯（林美版16:40開始）。
- 17:40移車前往晚餐；18:15–19:40葷食礁溪膳館／素食長春素食名人館（分開用餐時依實際人數訂位）。
- 19:40餐後回飯店停車，20:05步行湯圍溝，雨天取消。

### 週日 11/29｜退房 → 飯店早午餐 → 梅花湖 → 三清宮 → 明都晚餐 → 泰山
- 09:30–09:50 先退房，行李寄放大廳。
- 10:00–11:30 長榮鳳凰酒店桂冠自助早午餐，不另安排午餐。
- 11:30–11:50 領取行李、取車；預留行車與停車約50分鐘。
- 12:40–13:40 梅花湖散步或視現場租車，不強求完整環湖。
- 14:00–14:50 三清宮參拜與觀景。
- 15:00北返台北；四人同車符合國5週日15:00–20:00常態高乘載（至少3人，含駕駛及孩童），仍須查即時路況。
- 18:00 士林明都大自然素食館四人合菜（尚未訂位；早到可詢問17:30入席）。
- 19:30晚餐後取車返回泰山，約19:50–20:00抵達，依現場路況。

## 道路順序與車程核對

以 OpenStreetMap／OSRM 公開道路網比較景點順序，餐廳部分使用附近道路座標近似，僅供比較方向與繞行，不是店門精確導航，也不含即時車流。

- 飯店 → 龍潭湖：約8.4公里／14分鐘。
- Mercy 暮曦蔬食創意料理 → 龍潭湖 → 飯店：導航已更新為玉龍路一段55號；不沿用舊餐廳地址的 OSRM 車程估算，出發時以 Google Maps 即時路線為準。
- 梅花湖 → 三清宮：約2.9公里／7分鐘。
- 三清宮 → 泰山仁愛路：約82.1公里／82分鐘（OSRM無塞車模型）。

因此週六午餐優先、龍潭湖或林美擇一，可能有小幅折返但降低用餐風險；週日保留冬山兩景點同區安排、四人同車直接北返士林明都。晚餐後取車返回泰山。
