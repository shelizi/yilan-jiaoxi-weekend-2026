## 11/21 路線與車程審查：少繞路模式（預設）

先前的 Google Maps 路線僅驗證網址格式與途經點，沒有驗證實際道路繞行。這輪以餐廳地址、官方開放與時段資料、OpenStreetMap / OSRM 道路網做了初步地理比較，並確認選舉交通管制資訊。

**週六交通重點：**
- 高公局 2026/10/28 交通新聞稿預估 **11/28 國5南向 09:00–16:00 可能壅塞**；因此北投國小 08:00 投票、08:50–09:10離開後，11:20 抵達五峰旗僅為建議目標，不是保證。投票排隊、停車、國五車流都可能延誤。
- **預設「✿ 少繞路・輕鬆」**：泰山仁愛路 → 北投國小投票 → 五峰旗瀑布 → 特色午餐（葷／素） → 礁溪長榮鳳凰酒店 → 晚餐 →（天氣許可）湯圍溝 → 飯店。林美石磐為「⛰ 完整雙步道」選項，只有時間充裕才加走。
- **餐廳準時優先**：如果 Google Maps 預估無法趕上午餐訂位，按「塞車直達午餐」連結，從北投國小直接導航到餐廳再到飯店，省略五峰旗或其餘山區景點。
- 「完整雙步道」路線：北投 → 五峰旗 → 明溱（素食午餐）→ 林美石磐 → 飯店。若採同一套地理錨點比較，兩個景點比僅五峰旗多約 **13 公里當地道路、29 分鐘無塞車車程**。**但這是附近道路的近似地圖模型，不是精確店址或未來即時 Google Maps 車程**。林美開放 0–0.9K，雨天應取消。
- OSRM 較差的「五峰旗→明溱→林美→飯店」與改為「五峰旗→林美→明溱→飯店」道路里程幾乎相同，且後者午餐可能太晚而違反明溱 14:30 午餐結束時間，因此**不以重新排列所有景點強行聲稱更省時間**；改用自願加點與停留緩衝更合理。
- 長榮飯店到長春素食名人館約 3–4km 當地道路（公開道路模型、近似店址），不屬於重大跨區折返。

**週日交通重點：**
- 礁溪飯店 → 外澳 → 石港春帆（葷素皆可）→ 北關 → 泰山。公開道路模型估算外澳與石港春帆所在濱海路一段相近，站序約會有 1 公里內的小幅折返；改為先吃午餐再看海只省約 1–2 公里，但早餐才剛吃過不久、午餐不宜排太早，所以保留更合理的 12:40 午餐。
- 11/29 下午回程是選舉返鄉回程流量集中時段，出發前使用 **高公局1968** 和 Google Maps 即時比對：走國5/雪隧或台2/台62，看哪一條當時更快。不要先承諾無回頭路，也不要用 OSRM「無即時車流」時間保證到家時間。
- 雨天取消山路或海岸危險步道，改金車室內海洋生態展示與蘭陽博物館；原定週日飯店早餐及葷素餐廳維持。

**道路審查方法及限制：**
- OSRM 公開道路路網估算用於**比較不同景點順序**，非實際 Google Maps 到店距離；明溱、長春、石港春帆部分點位以所在道路附近代替，誤差及臨時交通管制未含。
- 路線、地址、時段、餐廳是否可訂位需出發前以店家、官方公告與 Google Maps 即時路況再次確認。
